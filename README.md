
# PNWCTF — Web Security CTF Platform
(IN PROGRESS)
A CTF challenge platform designed to demonstrate and teach common web vulnerabilities in a controlled environment.
Features:
* MySQL database backend connected via phpMyAdmin
* Session tracking across challenges
* Prepared statements protecting non-challenge endpoints
* Intentionally vulnerable challenge endpoints for educational exploitation

Challenges

* Web1: SQL Injection via login bypass
* Web2: Advanced SQLi payload crafting
* Web3: Path Traversal (in progress)

Note: This is an intentionally vulnerable application built for educational purposes. Do not deploy on a public network.
